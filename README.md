# Smart IoT Sensor Dashboard Pro



## Overview
A professional IoT sensor dashboard built using ESP32, DHT22, OLED, and Flask.

## Features
- Real-time monitoring
- OLED display
- Web dashboard
- CSV logging
- Temperature alerts
- Cloud integration

## Tech Stack
- ESP32
- Arduino IDE
- Flask
- Python
- HTML/CSS
- DHT22
- OLED

## Architecture
ESP32 → Sensor → Serial → Flask → Web Dashboard

## Future Scope
- AI anomaly detection
- Firebase cloud sync
- Mobile app integration
- MQTT protocol
